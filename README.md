# ☕ Café Luna

Landing page profesional para una cafetería de especialidad, desarrollada como proyecto de portafolio.

🌐 **Demo en vivo:** [nahuelprogram17.github.io/cafe-luna](https://nahuelprogram17.github.io/cafe-luna)

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (variables, Grid, Flexbox, animaciones)
- JavaScript vanilla (Intersection Observer, eventos DOM)
- Git & GitHub para control de versiones
- GitHub Pages para deploy

## Características

- Diseño responsive (mobile y desktop)
- Navegación con menú hamburguesa en mobile
- Animaciones al hacer scroll
- Formulario de contacto con feedback visual
- Paleta de colores y tipografía personalizadas
